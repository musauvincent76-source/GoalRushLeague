# GoalRush League

GoalRush League is a football management and multiplayer match game inspired by Dream League Soccer.

## Overview
GoalRush League is an original football game where players build and manage a club, recruit players, improve their skills, and compete in online football matches.

## Features
- Team creation and club management
- Player roster and transfer system
- Formation and tactics selection
- Match gameplay mechanics
- Rewards and economy system
- Multiplayer matchmaking foundation
- Leaderboard and league progression

## Tech Stack
- Unity 2022 LTS
- C#
- Photon Fusion
- Firebase / PlayFab
- PostgreSQL / MongoDB

## Setup
1. Install Unity Hub and Unity 2022 LTS
2. Create a new Unity project
3. Import Photon Fusion if using multiplayer
4. Clone this repo
5. Add scripts from the source structure
